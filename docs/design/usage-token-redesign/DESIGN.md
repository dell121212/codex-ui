# AI Provider 用量与官方额度看板 — DESIGN.md

## 1. 文档身份与适用范围

本文件是该本地桌面产品“用量概览”页面的唯一设计合同。设计事实来自两张给定界面截图、用户在本次任务中锁定的产品行为，以及当前 Warm Editorial 设计系统。

目标技术栈为 Neutralino、React 19、Tailwind 4 与 Appica UI 1.0.0。本文件只规定信息架构、视觉 Token、Appica 组件映射、响应式、交互状态和可访问性；不生成组件代码，不改变 Provider 接口、数据结构、缓存、session 文件、重置策略或任何真实副作用。

只采用一套 Warm Editorial 方向：暖纸张画布、深褐正文、稳定 UI sans 数据数字、陶土单强调、低阴影、清晰工具密度。不得混入玻璃拟态、深色科技风、霓虹或另一套品牌色。

### 1.1 用户覆盖：Token 展示优先级

本次用户要求覆盖原先“衬线数据数字”与旧的整数／`k` Token 展示方向，但只覆盖 Token 的显示层，不覆盖其余 OpenDesign 事实。所有用户可见 Token 体量统一使用十进制 M（`1M = 1,000,000`），最多三位小数并去除非必要尾零；`0` 固定为 `0.000M`，正数 `1..999` 显示 `<0.001M`，不可用值显示 `—`。业务层继续保存原始非负整数。

Token 大数字、周期数字、Provider 用量与模型用量使用项目 UI sans，并启用 `font-variant-numeric: lining-nums tabular-nums`；不得回退到 Georgia、Times 或 generic serif。每个缩写值的 title／aria-label 保留精确逗号分隔整数与 `Token` 单位。页面标题等非 Token 角色仍遵循其原有 Warm Editorial 事实。

## 2. 产品事实与不可变行为

### 2.1 必须保留的能力

- Provider 的添加、选择、拖拽编排与移除。
- 用量分析、模型列表、额度环、周期信息、设置与真实刷新。
- 陪伴角色，但只作为低调辅助，不得承担主数据表达。
- 官方 ResetPanel 的真实状态、次数、权限、确认和副作用。
- 缓存、真实数据、陈旧数据提示与失败回退。
- 所有既有入口与副作用均保持可发现、可操作，不以静态展示代替。

### 2.2 数值语义必须严格分离

1. **当前周期主值永远是本地 Token。** 页面主数字、周期卡主数字和 Provider 详情主数字均读取当前周期本地 Token，不得用官方 quota 百分比替换。
2. **官方 quota 百分比只允许出现两处：**额度环中心与“官方额度”字段。标题、周期条、当前周期卡、companion、Provider 标签与本地小计不得重复显示 quota 百分比。
3. **周期条只表达时间周期进程。** 它根据真实周期起止时间显示已过／剩余进度，不表示 quota 消耗，也不显示百分比文案。周期未知时显示中性空轨与“周期时间不可用”。
4. **当前周期、当月、总计始终是一条横行。** 任何视口都不得堆成三行；空间不足时只能横向滚动。
5. **上一周期 Token 与当前周期同处且紧邻。** 它位于当前周期主值右侧，同一视觉组、同一卡片、同一行；不得移到 tooltip、脚注或下一行。
6. **新增“本地 Token 小计”。** 该数值来自独立 checkpoint；用户可将小计归零。归零只更新该 checkpoint，不改变当前周期、当月、总计、session 文件、缓存中的原始会话记录或官方额度。
7. **两种重置不可混淆。**“清零本地小计”与“重置官方额度”在命名、空间层级、容器、颜色和按钮样式上必须明显不同；不得都简称“重置”。
8. 所有数字来自真实数据或已有缓存。没有值时显示“—”及真实状态说明；禁止用截图示例值、随机值、估算增长率或假成功状态填充。

## 3. 信息层级

从高到低固定如下：

1. **当前周期本地 Token：**页面唯一主值，42 px UI sans 等高等宽数字。
2. **周期语境：**周期条、真实起止／重置时间，以及紧邻当前周期主值的上一周期 Token。
3. **官方额度：**额度环与官方额度字段；图形重要但不压过当前周期 Token。
4. **Provider 身份与健康：**名称、真实连接／余额状态、刷新时效。
5. **横向用量组：**当前周期、当月、总计，顺序固定且永不换行。
6. **本地 Token 小计：**独立、可归零的工具性统计，位于横向用量组之后，不伪装成第四个周期指标。
7. **官方 ResetPanel：**在 Provider 卡内作为高后果操作区；入口清楚但默认不抢主数据。
8. **Provider 编排与模型列表：**可扫描、可拖拽，服务于切换上下文。
9. **Companion：**最低视觉优先级，不承载 quota 百分比、主操作或错误阻断。

### 3.1 额度环、周期条与本地小计的相对关系

- 额度环是“官方额度”的唯一图形，直径 104 px；中心百分比 28 px，标题明确写“官方额度”。
- 额度环底轨使用 `--border-soft`，默认有效弧使用 `--fg-2`；只有真实业务阈值进入警告或紧急状态时才分别切换为 `--warn` 或 `--danger`。健康状态以文字和 `--success` 状态点表达，不把整只环染绿。
- 当前周期本地 Token 与周期条处于同一主信息列。Token 数字在上，上一周期 Token 紧邻其右，周期条在下；周期时间文本跟随周期条。
- 周期条高度 8 px，底轨使用弱边界色，进度使用前景次级色；不得复用额度环的百分比或制造第二个 quota 指示器。
- 本地 Token 小计是额度卡之后的独立 72 px 工具条。它不进入额度环，不进入周期条，也不改变三项周期汇总。
- 当屏幕阅读器读取时，顺序为“当前周期本地 Token → 上一周期 Token → 周期时间 → 官方额度 → 重置时间 → 本地小计”。

## 4. Warm Editorial 视觉 Token

所有实现值必须从下表集中映射到 Appica 主题层。页面不得自行增加颜色、字号、间距、圆角或阴影等级。

### 4.1 颜色

| Token | 固定值 | 角色 |
|---|---|---|
| `--bg` | `#fbf6ee` | 应用主画布 |
| `--surface` | `#fffdf8` | Card、Tabs 容器与输入表面 |
| `--surface-warm` | `#f1e3cf` | 官方 ResetPanel 与少量暖色提示底 |
| `--fg` | `#201914` | 主文字、主图标、大数字 |
| `--fg-2` | `#4c4037` | 次级文字与周期条进度 |
| `--muted` | `#7a6d63` | 元数据、上一周期标签、禁用前景 |
| `--meta` | `#9b5b32` | 元信息与克制强调 |
| `--border` | `#ded2c3` | 外边界、按钮与分隔线 |
| `--border-soft` | `#eee4d7` | 内部分隔、周期条底轨 |
| `--accent` | `#9b5b32` | 当前周期主值或主操作；同屏最多两次 |
| `--accent-on` | `#ffffff` | 只用于 accent 填充按钮文字 |
| `--success` | `#4f8a4f` | 真实成功、余额健康 |
| `--warn` | `#c9822f` | 官方额度警告与临近重置 |
| `--danger` | `#b33a3a` | 官方重置确认、错误、不可逆移除 |

颜色不得单独承担状态；任何 success、warn、danger 都必须同时有明确文字或图标语义。

### 4.2 字体与数字排版

| 角色 | Token／值 | 用法 |
|---|---|---|
| Display | Georgia, “Times New Roman”, serif | 页面标题等非 Token Display 角色；不用于 Token 数字 |
| Token Display（用户覆盖） | 项目 UI sans；`font-variant-numeric: lining-nums tabular-nums` | 当前周期主值、周期汇总、Provider／模型 Token 体量与本地小计 |
| Body | Inter, system-ui, sans-serif | 中文界面、按钮、Tabs、说明 |
| Mono | “SF Mono”, ui-monospace, Menlo, monospace | Provider ID、技术标识；不用作普通统计数字 |
| 字号阶梯 | 12 / 14 / 17 / 20 / 28 / 42 / 64 / 88 px | 不得插入中间魔法字号 |
| 主数字 | 42 px / 1.0 / 600 | 当前周期本地 Token |
| 环内数字 | 28 px / 1.0 / 600 | 官方 quota 百分比 |
| 汇总数字 | 28 px / 1.05 / 600 | 月、总计与周期卡 |
| UI 正文 | 14 或 17 px / 1.62 | 控件与解释 |
| 元数据 | 12 px / 1.4 | 更新时间、来源、上一周期辅助标签 |

所有 Token、金额、百分比、倒计时和计数启用 lining、tabular numerals。Token 只使用十进制 `M` 单位，不再显示 `k` 或用户可见的原始整数；小数点、`M` 与数字基线对齐，单位与数字间保留 4 px 视觉间隔。大于 40 px 的 Display 字距为 -0.025em，其余不压缩。

### 4.3 间距、圆角、边界与阴影

- 间距只使用 4、8、12、16、20、24、32、48 px。
- Card 外圆角 16 px；大面板可用 24 px；输入／图标按钮 10 px；Provider 计数和状态标签可用 pill。
- 普通边界统一 1 px `--border`；面板内部为 1 px `--border-soft`；禁止彩色左边框。
- 静态元素无阴影。只有悬停中的可拖拽 Card、下拉层和浮层使用一级阴影：y 20 px、blur 52 px、`rgba(32, 25, 20, 0.12)`。
- 焦点环为 4 px、`rgba(155, 91, 50, 0.24)`，外扩且不可被 Card 裁切。
- 动效时长只使用 150 ms 与 240 ms，曲线为 `cubic-bezier(0.2, 0, 0, 1)`。

## 7. 本地 Token 小计

### 7.1 结构

- 容器为独立 Appica Card，940 与 620 均高 72 px、16 px 圆角、1 px `--border`、无阴影。
- 左侧依次为标签“本地 Token 小计”、真实数值、checkpoint 建立／上次归零时间；没有 checkpoint 时间时显示“尚未归零”，不得造日期。
- 右侧使用次级 outline Button，固定文案“清零本地小计”。按钮高 36 px，文字与边界使用 `--fg-2`／`--border`，不使用 danger、warn 或填充强调色。
- 归零前如现有产品需要确认，确认文案必须再次写明“只清零本地 Token 小计，不影响周期、月度、总计、session 或官方额度”。

### 7.2 数据与副作用

- 小计值计算为真实本地 Token 累计值减去独立 checkpoint 值。
- 归零成功只写入新的 checkpoint，并重新计算小计为真实零值。
- 当前周期、当月、总计、上一周期、Provider session 文件、原始事件、缓存历史和官方 quota 必须保持不变。
- 失败时保留原小计与 checkpoint，不得先乐观清零再静默回滚。

## 8. 官方 ResetPanel

- Panel 固定留在当前 Provider 卡底部，使用 `--surface-warm`，和本地小计相隔一个完整区域。
- 标题为“官方额度重置”或沿用现有官方命名；执行按钮必须明确写“重置官方额度”。
- 按钮使用 danger outline；只有确认层的最终提交可使用 danger fill。不得与本地小计的中性 outline 样式相同。
- Panel 必须显示真实可用次数、限制或资格；没有数据时禁用按钮并解释原因，不显示假次数。
- 触发后只按现有官方 ResetPanel 契约更新官方额度和相关真实状态；不得顺带清零任何本地 Token 指标。

| 官方重置 | `Card` 内 Panel + `Button` | danger outline，确认时 danger fill；与本地清零隔离 | 官方 ResetPanel 真实动作 |
| 刷新 | `Button` | 由项目主题层映射为图标按钮；44 × 44 px 热区，加载时旋转仅在未启用 reduced-motion 时发生 | 真实刷新、缓存与错误回退 |
| 设置 | `Button` | 由项目主题层映射为图标按钮；保留原设置入口与可访问名称 | 真实设置页／弹窗 |
| 添加 Provider | `Button` | 940 可显示文字；620 保留清晰 tooltip 与可访问名称 | 真实添加流程 |

### 9.1 Button 视觉变体

- Primary：只用于页面唯一主行动；accent fill、accent-on 文字，44 px 最小高度。
- Secondary：1 px `--border`、透明背景、`--fg` 文字。
- Local-clear：Secondary 的紧凑版本，高 36 px，文案固定“清零本地小计”，永不使用 danger。
- Official-reset：danger outline，高 36 px，文案固定“重置官方额度”；确认层最终提交才 danger fill。
- Icon：可见图标 20 px，热区至少 44 × 44 px；不得用无标签的字符代替图标。

## 10. 状态矩阵

### 10.1 Default

- Card 使用 `--surface`、1 px `--border`、无阴影。
- 当前 Provider Tab 使用 `--surface-warm` 与 600 字重；不使用整块 accent 填充。
- 当前周期主值使用 `--fg`；真实需要强调时只允许数字局部使用 `--accent`。
- Companion 静止、弱对比，不显示主动气泡。

### 10.2 Hover

- Button 背景只发生一个层级的轻微变化；文字与边界对比不得下降。
- 可拖拽 Provider Card／Tab 显示一级抬升和明确抓取光标；普通静态 Card 不抬升。
- 链接使用浅 accent 背景并移除下划线；不得位移或缩放。

### 10.3 Focus-visible

- 所有 Button、Tab、拖拽把手、周期横滚容器和可交互 companion 使用 4 px 外焦点环。
- 焦点环不得被 Card 的 overflow 裁掉；滚动容器获取焦点时自动让当前项完整可见。
- 只使用 `focus-visible`，鼠标点击不制造永久焦点噪声。

### 10.4 Disabled

- 保留控件尺寸与文案，前景使用 `--muted`，边界使用 `--border-soft`，不允许 opacity 低于 0.55。
- 禁用原因必须通过邻近说明或 tooltip 可知；不得只变灰。
- 刷新中、官方重置处理中、本地清零处理中均禁止重复提交。

### 10.5 Reset success

- **本地小计归零成功：**小计真实变为零值，出现紧邻小计工具条的 success 行内反馈“本地小计已归零”；当前／月／总计、session 与官方额度不闪动、不重取值。
- **官方额度重置成功：**只在 ResetPanel 内显示“官方额度已更新”，然后以真实响应更新额度环与额度字段；不得显示“本地数据已清空”。
- success 反馈持续时间与关闭策略沿用现有产品；不使用 confetti、弹跳或全屏遮罩。

### 10.6 Error

- 刷新失败保留最后一次可信缓存，在 Provider 头部显示“数据可能已陈旧”与真实更新时间，并提供重试。
- 本地小计清零失败时保留旧值与旧 checkpoint，错误贴近本地小计按钮。
- 官方额度重置失败时额度环与字段保持旧值，错误只进入 ResetPanel；不得波及本地统计。
- 无缓存且无真实数据时以“—”代替数值，并显示可操作的错误原因；禁止把零当作未知。

### 10.7 Loading 与 empty

- 数字加载骨架必须固定原尺寸，避免布局跳动；同一区域只出现一个加载提示。
- Provider 为空时保留 Provider 编排 Card 和真实“添加 Provider”入口；额度卡、周期横行与小计不显示假结构数据。
- 模型列表为空时明确区分“Provider 尚未返回模型”与“请求失败”。

## 11. 键盘、辅助技术与 reduced-motion

### 11.1 键盘顺序

Tab 顺序固定为：左侧导航 → 页头刷新／设置 → 添加 Provider → Provider Tabs → 拖拽把手 → 移除 → 周期横滚容器 → 本地小计清零 → 官方额度重置。视觉顺序与 DOM 顺序保持一致。

- Provider Tabs 使用左右方向键切换，Home／End 到首尾。
- Provider 拖拽：Space 拾取，左右方向键移动，Space 放下，Escape 取消；每次变化播报“已移动到第 N 位”。
- 周期横滚容器可获得焦点；左右方向键按单卡步长滚动，Home／End 到首尾，不形成键盘陷阱。
- Enter／Space 激活 Button；Escape 关闭确认层并把焦点还给触发按钮。
- 所有图形进度提供名称、当前值、最小值与最大值；周期条的可访问名称必须是“周期时间进度”，不是“额度使用率”。
- Companion 若纯装饰则对辅助技术隐藏；若保留互动，必须有具体动作名称且排在数据操作之后。

### 11.2 Reduced motion

- 禁用 companion 漂浮、眨眼、呼吸、弹跳等循环动画。
- 额度环、周期条与数字不做补间计数，直接显示最终真实值。
- 横向滚动使用即时定位，不强制平滑滚动。
- 刷新图标不连续旋转；以静态“刷新中”状态与 `aria-busy` 表达。
- 必要的显隐反馈不超过 50 ms，且不得依赖移动或缩放传达状态。

## 12. Companion 规则

- 940 px 最多显示 72 × 72 px 角色本体；620 px 无气泡，必要时完全隐藏。
- 不显示官方 quota 百分比、本地 Token 主值、错误详情或重置入口。
- 不覆盖主内容，不拦截横向／纵向滚动，不制造额外 44 px 以上布局占位。
- 只有真实、低优先级、非阻断信息才可出现；没有真实状态时保持安静。
- 任何循环动效都必须可被 reduced-motion 完全关闭。

## 13. 禁止项

- 禁止把官方 quota 百分比当作当前周期主值，或在额度环与额度字段之外重复显示。
- 禁止把周期条画成第二个 quota 进度条。
- 禁止将当前周期、当月、总计堆成三行；620 px 及更窄必须横滚。
- 禁止把上一周期 Token 移出当前周期卡、放到下一行、tooltip 或隐藏菜单。
- 禁止让本地小计归零修改当前／月／总计、session、缓存历史或官方额度。
- 禁止两个重置入口使用相同文案、相同颜色、相同容器或相同按钮变体。
- 禁止假数据、假按钮、无响应控件、演示路由、静态成功态与编造阈值。
- 禁止 Companion 与数据竞争、显示 quota、覆盖操作或在窄窗强占空间。
- 禁止装饰性色彩渐变、毛玻璃、霓虹、深色科技背景、卡片墙、Emoji 图标与彩色左边框。
- 禁止纯视觉拖拽而无键盘路径、只靠颜色表达状态、隐藏焦点或小于 44 × 44 px 的操作热区。
- 禁止在各页面零散覆盖 Appica 样式、堆叠 `!important` 或重复手写 Button、Tabs、Card 基础组件。
